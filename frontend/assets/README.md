# Expo Assets

This folder should contain the following image files for the Expo app:

- `icon.png` (1024x1024) - App icon
- `splash.png` (1242x2436) - Splash screen image  
- `adaptive-icon.png` (1024x1024) - Android adaptive icon
- `favicon.png` (32x32) - Web favicon

You can generate these using tools like:
- https://expo.dev/tools/app-icon
- https://expo.dev/tools/splash-screen

For now, the app will work without these files, but Expo will show warnings.
